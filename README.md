# Вежа Годинникаря (Clockmaker Tower) — Unity 2D

2D-платформер із фізичними головоломками: юний годинникар Тео прокинувся в закритій вежі, де час зупинився.
Щоб вибратися, потрібно пройти п'ять поверхів, зібрати деталі головного механізму й запустити його знову.

| | |
|---|---|
| Версія гри | 1.0.0 (тег `v1.0.0`) |
| Двигун | Unity **6000.5.10f1** |
| Цільова платформа | Windows 10/11, 64-bit |
| Графічні API | Direct3D 12 (за замовчуванням), Direct3D 11 (параметр `-force-d3d11`) |

## Гілки репозиторію

| Гілка | Вміст |
|---|---|
| `main` | Проєкт Unity (цей README): код, сцени, налаштування, інструменти релізу (`ReleaseKit/`). Відкривається через Unity Hub. |
| `release` | Готова збірка гри для Windows (`ClockmakerTower.exe` і супровідні файли) з власним README. Unity не потрібен. |

## Швидкий старт (відкрити проєкт)

1. Встановіть **Unity Hub** і редактор **Unity 6000.5.10f1** (з модулем *Windows Build Support*, якщо плануєте збірку).
2. Клонуйте репозиторій (гілка `main`).
3. Unity Hub → **Add → Add project from disk** → оберіть папку проєкту.
4. Дочекайтеся імпорту й компіляції (у Console не має бути червоних помилок).
5. Відкрийте сцену `Assets/Scenes/Final_UI.unity` і натисніть **Play**.

Сцена `Final_UI` — фінальна, повна гра з п'яти рівнів, вона вже є в репозиторії. Якщо сцену потрібно перебудувати,
виберіть **Clockmaker → Build Full Game (5 рівнів)**. Старий пункт **Build Final Scene** створює лише однорівневу демо-сцену,
для фінальної гри його не використовуйте.

| Дія | Клавіші |

Службові клавіші для вимірювань: **F5** — запустити дослід продуктивності, **F3** — показати/сховати панель.

Стартове меню: **Нова гра**, **Продовжити** (з'являється після першого пройденого рівня), **Налаштування звуку**, **Вийти**.
Прогрес зберігається після кожного рівня (у реєстрі Windows, `HKEY_CURRENT_USER\Software\ClockmakerStudio\Clockmaker Tower`).

## Рівні та правила

| № | Рівень | Особливості |
|---|---|---|
| 1 | Майстерня | Навчальний: ящик + плита + брама, NPC, сторожі, прірва |
| 2 | Зала шестерень | Рухомі платформи (горизонтальна й ліфт), сходи, шипи, контрольні точки |
| 3 | Маятникова зала | Три маятники, ящик і брама, сторож |
| 4 | Лабораторія терезів | Дві брами: від одного ящика та від двох ящиків (вага), два сторожі |
| 5 | Дзвіниця | Бос: тричі стрибнути йому на голову; маятники над ареною |

- На кожному рівні зберіть усі шестерні й потягніть важіль біля виходу (E). Вихід відчиняється лише за виконання умов рівня.
- Нажимні плити реагують на вагу: гравець важить 1, ящик — 2; деякі брами потребують кількох ящиків.
- Сторожі завдають шкоди ударом. Оглушити сторожа можна, стрибнувши йому на голову.
- Здоров'я — 3 одиниці. Смерть повертає гравця на останню контрольну точку (прапорець) рівня.
- Після кожного рівня — екран статистики; після п'ятого — екран перемоги із загальним часом.

## Збірка релізу (Windows)

1. **File → Build Profiles → Windows**, профіль *Release*: Scene List лише `Final_UI`, **Development Build** і **Script Debugging** вимкнені.
2. **Clockmaker → Release → Build Windows Release** — результат у `Builds/Release/` (поза `Assets`): exe, README, ліцензії, чек-лист,
   `run_tests.bat`, `build_info.txt`.
3. Символи компіляції релізу: `CLOCKMAKER_RELEASE`, `CLOCKMAKER_OPT_AI`, `CLOCKMAKER_OPT_HUD`.
4. Закрийте Unity й запустіть `run_tests.bat` із папки збірки: 6 автоматичних прогонів (3 роздільності × Direct3D 12 / 11),
   приблизно 8 хв; результати — у `test_results/*_summary.txt`.
5. Функціональне тестування: `ReleaseKit/TEST_CHECKLIST.md` (запускайте гру з папки збірки, без відкритого Unity).

Вміст `ReleaseKit/`: `run_tests.bat`, `TEST_CHECKLIST.md`, `README_RELEASE.md` (README для гравця), `THIRD_PARTY_NOTICES.md`.

Параметри запуску збірки (необов'язкові): `-novsync`, `-force-d3d11`, `-screen-width 1280 -screen-height 720 -screen-fullscreen 0`,
`-autobench` (службовий дослід продуктивності).

## Вимірювання та оптимізація (лабораторна 15)

Версії A / B1 / B2 відрізняються лише символами компіляції (`#if`), зміни видно в `EnemyAI.cs`, `GameManager.cs`, `DayNightCycle.cs`.

| Версія | Символи | Що змінено |
|---|---|---|
| **A** | — | Вихідна версія |
| **B1** | `CLOCKMAKER_OPT_AI` | ШІ ворога: `Physics2D.Raycast` зі спільним буфером замість `RaycastAll` + сортування |
| **B2** | `CLOCKMAKER_OPT_AI` + `CLOCKMAKER_OPT_HUD` | + HUD: рядки кешуються й перебудовуються лише при зміні стану |

Збірки для порівняння: меню **Clockmaker → Perf →** *Build A / Build B1 / Build B2 / Build Final*. У збірці натисніть **Грати**, потім **F5**:
10 с прогріву + 60 с запису, гравця веде скрипт `PerfBot` (однаковий маршрут). Підсумок зберігається у
`perf_<версія>_<час>_summary.txt` у `%USERPROFILE%\AppData\LocalLow\<Company>\<Product>\`.
Зміна у відсотках: **(A − B) / A × 100 %** для метрик, де менше — краще.

## Якщо виникли проблеми

- **Помилка про `UnityEngine.Input` / Input System:** *Edit → Project Settings → Player → Active Input Handling → Both* і перезапустіть редактор.
  Input System у `manifest.json` не прописано навмисно (версія має відповідати редактору); без нього інтерфейс працює зі старим Input Manager.
- **Не відображається текст / помилка TextMeshPro:** *Window → TextMeshPro → Import TMP Essential Resources → Import*.
- **Немає звуку з мікшера:** виконайте **Clockmaker → Wire Audio Mixer** (мікшер `GameAudio` з групами *Music* і *SFX* та параметрами
  `MusicVolume`, `SfxVolume`).
- **Зникли ефекти частинок у збірці:** у `Packages/manifest.json` має бути модуль `com.unity.modules.particlesystem`
  (у репозиторії він є).
- **Постобробка (URP, необов'язково):** проєкт працює на вбудованому рендері; Bloom, Vignette тощо підключаються вручну:
  *Package Manager → Universal RP → Install*, створіть *URP Asset (with 2D Renderer)*, призначте його в *Project Settings → Graphics* і
  *Quality*, додайте *Global Volume* з потрібними ефектами, а на *Main Camera* увімкніть *Post Processing*.
- Код сумісний із Unity 2022.3 LTS і Unity 6+ (`PhysicsCompat.cs` підставляє `linearVelocity` або `velocity`), але фінальну збірку
  перевірено на **Unity 6000.5.10f1**.
