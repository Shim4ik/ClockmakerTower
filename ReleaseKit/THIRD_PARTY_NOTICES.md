# Сторонні ресурси та ліцензії

| Ресурс | Призначення | Автор / джерело | Ліцензія |
|---|---|---|---|
| Unity Engine 6000.5.10f1 | Ігровий рушій | Unity Technologies | Умови використання Unity (відповідно до плану ліцензії автора проєкту) |
| Unity UI / TextMeshPro (пакет com.unity.ugui) | Інтерфейс | Unity Technologies | Unity Companion License |
| Liberation Sans Regular (`LiberationSans-Regular.ttf`) | Шрифт інтерфейсу (підтримує кирилицю) | Red Hat / Liberation Fonts | SIL Open Font License 1.1 — https://openfontlicense.org |

## Власні матеріали
Створені автором проєкту програмно (редакторські скрипти проєкту) і не потребують ліцензій третіх осіб:
- текстури (цегла, дошки, метал), спрайти (квадрат, шестерня, шип, світіння), матеріали;
- звукові ефекти (стрибок, кроки, збір шестерні, важіль, двері, удар тощо) та фоновий звук вежі;
- музична композиція «Tower theme» (`mus_tower_theme.wav`);
- анімації (кліпи Animator), префаби систем частинок, код гри.

## Примітка про шрифт
Шрифт Liberation Sans поширюється за SIL OFL 1.1: його можна використовувати та поширювати разом із застосунками;
шрифт не продається окремо, оригінальну назву шрифту при зміні файлу слід змінювати. У проєкті шрифт не модифікувався.
