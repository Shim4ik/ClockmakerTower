# Чек-лист функціонального тестування релізної збірки

Запускайте гру з папки збірки (не з Unity), відкритий Editor не потрібен. Відмічайте результат кожного пункту.

| № | Що перевірити | Очікуваний результат | Результат |
|---|---|---|---|
| 1 | Старт гри | Відкривається стартове меню, музика грає, помилок немає | |
| 2 | «Нова гра» | Починається рівень 1, з'являється HUD і рахунок шестерень | |
| 3 | Керування | A/D біг, Пробіл стрибок, E взаємодія | |
| 4 | Пауза / налаштування (Tab) | Гра на паузі, повзунки змінюють гучність музики й ефектів окремо | |
| 5 | Кнопка «Перевірити звук» | Один клік на одне натискання | |
| 6 | Збір шестерні, важіль, двері | Звуки та ефекти є, лічильник правильний | |
| 7 | Поразка | Смерть (шипи, пастки, падіння) повертає на контрольну точку | |
| 8 | Перезапуск рівня (R) | Рівень повертається в початковий стан | |
| 9 | Перемога на рівні | Екран статистики, «Далі» (Enter) відкриває наступний рівень | |
| 10 | Проходження рівнів 2–5 | Рухомі платформи, маятники, терези, бос працюють | |
| 11 | Перемога у грі | Екран перемоги із загальним часом, «Грати ще раз» | |
| 12 | Збереження прогресу | Після виходу з'являється «Продовжити» | |
| 13 | Вихід | Кнопка «Вийти» закриває гру без помилок | |
| 14 | Зміна розміру вікна | Інтерфейс масштабується, текст читабельний | |
| 15 | Різні роздільності (скрипт `run_tests.bat`) | Гра працює стабільно, результати збережені | |
