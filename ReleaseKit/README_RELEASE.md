# Clockmaker Tower — «Вежа Годинникаря» (версія 1.0.0)

2D-платформер із фізичними головоломками. Годинникар-підмайстер Тео прокинувся в закритій вежі, де час зупинився.
Щоб вибратися, потрібно пройти п'ять поверхів, зібрати деталі головного механізму й запустити його знову.

## Технічні дані
| Параметр | Значення |
|---|---|
| Версія гри | 1.0.0 |
| Двигун | Unity 6000.5.10f1 |
| Цільова платформа | Windows 10/11, 64-bit |
| Тип збірки | Release (без Development Build та Script Debugging) |
| Графічний API | Direct3D 12 (за замовчуванням), Direct3D 11 (параметр `-force-d3d11`) |
| Режим вікна за замовчуванням | 1920 × 1080, вікно, розмір змінюється |

## Як запустити
1. Розпакуйте **весь** архів у окрему папку (не запускайте гру з архіву).
2. Запустіть `ClockmakerTower.exe` двічі клацанням. Усі файли поруч (`ClockmakerTower_Data`, `UnityPlayer.dll` та ін.) мають лишитись у тій самій папці.
3. Збереження прогресу — у реєстрі Windows (`HKEY_CURRENT_USER\Software\ClockmakerStudio\Clockmaker Tower`).

Параметри командного рядка (необов'язкові): `-novsync` — вимкнути вертикальну синхронізацію; `-screen-width 1280 -screen-height 720 -screen-fullscreen 0` — розмір вікна; `-force-d3d11` — графічний API Direct3D 11.

## Керування
| Дія | Клавіші |
|---|---|
| Рух | A / D або ← / → |
| Стрибок | Пробіл (утримуйте — вище) |
| Взаємодія (важіль, лампа, діалог із годинникарем) | E |
| Налаштування звуку / пауза | Tab (Esc — закрити) |
| Змінити час доби | N |
| Вимкнути/увімкнути звук | M |
| Перезапустити рівень | R |
| Далі (після рівня), «Грати ще раз» | Enter |

У стартовому меню: **Нова гра**, **Продовжити** (з'являється після першого пройденого рівня), **Налаштування звуку**, **Вийти**.

## Правила гри
- На кожному рівні зберіть усі шестерні й потягніть важіль біля виходу (E). Вихід відчиняється лише за виконання умов рівня.
- Ящики та нажимні плити: гравець важить 1, ящик — 2; деякі брами потребують кількох ящиків.
- Сторожі завдають шкоди ударом. Оглушити сторожа можна, стрибнувши йому на голову. Головного сторожа (рівень 5) потрібно оглушити тричі.
- Здоров'я — 3 одиниці. Смерть повертає гравця на останню контрольну точку (прапорець) рівня.

## Рівні
1. Майстерня — навчальний рівень. 2. Зала шестерень — рухомі платформи. 3. Маятникова зала — маятники-пастки.
4. Лабораторія терезів — брами, що відкриваються під вагою ящиків. 5. Дзвіниця — бос.
